# Accessibility / Acessibilidade

The repository documentation aims for semantic Markdown, descriptive links and text alternatives for essential graphics. The skill directs agents to treat WCAG 2.2 AA as a design target where applicable, but **does not certify compliance** for applications generated with it.

If you encounter inaccessible documentation or skill output, open a [Bug report](https://github.com/merlinfachetti/layout-first-engineering/issues/new/choose), including assistive technology/browser details if you are comfortable sharing them. Do not include sensitive medical data.

Contributions improving readable language, contrast guidance, keyboard patterns, reduced-motion behavior, error messages, semantics and testing are welcome. Document any unresolved limitations.
