# Community Code of Conduct / Código de Conduta

## Our commitment / Nosso compromisso

Layout-First Engineering is a public, international, collaborative open-source project. Everyone is welcome to propose changes, learn, ask questions and disagree constructively. Participants must treat each other with respect regardless of background, experience or identity.

## Expected / Esperado

- Be professional, patient and constructive; challenge ideas, not people.
- Give actionable feedback about design, engineering, tests and documentation.
- Protect people's privacy; remove credentials and identifiers from reports and screenshots.
- Respect third-party copyright, trademarks, license notices and project scope.
- Follow maintainer review decisions; disagreements may be discussed respectfully.

## Unacceptable / Inaceitável

- Harassment, threats, discriminatory attacks or repeated insults.
- Publishing another person's private information without permission.
- Spam, impersonation, deceptive attribution or intentionally malicious contributions.
- Public disclosure of sensitive vulnerability details before coordinated handling.

## Scope and moderation / Escopo e moderação

These standards apply to repository Issues, Discussions, Pull Requests, review comments and other official project collaboration spaces. The original maintainer, [@merlinfachetti](https://github.com/merlinfachetti), may warn participants, hide or remove content, lock threads, close PRs or report abusive behavior to GitHub, taking context and proportionality into account. Decisions are not guaranteed to be immediate.

For harassment or abuse, use GitHub's **Report content / Report abuse** feature, particularly when a private report is required. Do not disclose private reports in public Issues. This repository has no independently operated anonymous abuse-reporting service. Security issues follow [SECURITY.md](SECURITY.md), not public Issues.

## Attribution / Atribuição

The original work and maintainership remain credited to Merlin Fachetti; human contributors keep attribution for their actual contributions. Automated tools are not granted repository ownership or maintainer status.
