# Privacy & Data Handling Notice / Aviso de Privacidade

**Scope:** This notice describes the public GitHub collaboration practices of the **Layout-First Engineering source-code repository**. It is not a privacy policy for applications built *using* the skill, nor a substitute for [GitHub's own privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Last reviewed: 2026-10-16.

## What the project does / O que fazemos

The project publishes source code, documentation and reusable prompts. **The repository itself does not operate a website/app that registers end users, collect analytics through our own scripts, sell contributor data or ask users to submit credentials.** External providers (such as GitHub or optional AI/design services) have their own policies; using this skill does not automatically establish a privacy or security guarantee for them.

Public contributions may expose GitHub usernames, profile information, commit author names/emails as configured by contributors, comments, code, issue descriptions, PR metadata, timestamps and logs. **Public repositories and their forks can be indexed, cloned, mirrored and archived; removal is not guaranteed.** GitHub processes data as explained in its [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Minimization & safety / Minimização

- Use your GitHub username and, if desired, GitHub's private/noreply commit email setting.
- Do not submit passwords, tokens, API keys, `.env`, personal identification numbers, phone numbers, addresses, health data, private conversations, customer files or real user datasets.
- Before publishing logs/screenshots, redact private details. Prefer synthetic test fixtures and minimal reproducible examples.
- Do not submit third-party personal data without a lawful basis and authorization.
- Do not include private Figma/Drive/Claude/ChatGPT project content unless you are authorized to disclose it publicly.
- Never upload security exploit details via a public Issue: follow [SECURITY.md](SECURITY.md).

## Purposes and responsibilities / Finalidades

Maintainer review uses public contributions for project governance, code review, community discussion, incident response and project history. Repository discussions and content are stored and processed on GitHub; third-party processing and international data transfers, where relevant, should be assessed against GitHub's applicable notice. We do not assert that publishing this file automatically establishes GDPR compliance for any deployment, legal role, or jurisdiction.

If you wish to ask about or correct content that you submitted, contact the maintainer through an existing GitHub issue/PR without repeating sensitive data, or use the platform's own privacy/support mechanisms. Legitimate moderation, security and removal requests will be assessed according to applicable law, technical limitations, and GitHub capabilities. Git history, forks and independent clones can make complete erasure impossible for the maintainer alone.

**Before starting any separate hosted service, newsletter, contact form, mailing list, analytics or user database**, re-evaluate controller roles, purposes and legal bases, notices, processors, retention, transfers, rights requests, security, backups, and any required contact details under applicable law (including GDPR where it applies). That service will need its *own* appropriately reviewed privacy information.

### Legal review / Revisão jurídica

This is a project notice and privacy-by-design guidance, **not a legal opinion or proof of GDPR compliance**. If this repository begins to process personal information beyond ordinary GitHub collaboration, seek jurisdiction-specific legal review before launch.

Official context: [European Commission — GDPR principles](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/principles-gdpr_en), [information duties](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/obligations_en).
