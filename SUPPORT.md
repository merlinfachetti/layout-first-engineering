# Support / Suporte

**Start here:** [Manual Mestre PT-BR](docs/MANUAL-MESTRE.pt-BR.md), [Installation & Usage](docs/INSTALLATION-AND-USAGE.md), [FAQ](docs/OPEN-SOURCE-MAINTENANCE.pt-BR.md).

| Need / Necessidade | Where / Onde |
|---|---|
| Installation trouble, reproducible regression | [New Issue](https://github.com/merlinfachetti/layout-first-engineering/issues/new/choose) |
| Product-design approach, adoption, questions and ideas | [Discussions](https://github.com/merlinfachetti/layout-first-engineering/discussions) **after maintainers enable it** |
| Propose code/docs changes | [Pull Requests](https://github.com/merlinfachetti/layout-first-engineering/pulls), after reading [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security vulnerability | **Private** report via [Security Advisories](https://github.com/merlinfachetti/layout-first-engineering/security/advisories) if private reporting is enabled; see [SECURITY.md](SECURITY.md) |
| Privacy concern in a public submission | See [PRIVACY.md](PRIVACY.md); never post additional private data in the issue |
| Harassment / community moderation | Use GitHub's Report content function, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

The project is maintained on a best-effort volunteer basis. **No guaranteed response time, SLA, hosted service or paid support** is provided. Opening an Issue does not grant permission to access another person's accounts or infrastructure.
