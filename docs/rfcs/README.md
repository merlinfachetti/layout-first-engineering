# RFCs do Layout-First Engineering

Propostas versionadas de mudanças relevantes de arquitetura, contratos ou processo. Uma RFC
**não autoriza implementação** por si só: ela é aceita quando o proprietário aprova o PR que a
introduz. Status possíveis: `Proposta`, `Aceita`, `Rejeitada`, `Implementada`, `Substituída`.

| RFC | Título | Status |
|---|---|---|
| [0001](0001-core-contracts.md) | Contratos do core LFE v0.1 | Proposta |
| [0002](0002-vertical-slice-01.md) | Primeira fatia vertical: VS-01 "Lista de leituras" | Proposta |

*English summary: RFCs propose versioned changes; acceptance happens only through owner approval
of the introducing pull request.*
