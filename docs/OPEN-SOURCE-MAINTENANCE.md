# Community, security, privacy and maintenance

The comprehensive step-by-step maintainer guide is available in [Português (PT-BR)](OPEN-SOURCE-MAINTENANCE.pt-BR.md).

The project is under the MIT license with publicly proposed contributions (Issues, fork-based PRs), community governance (`GOVERNANCE.md`), conduct (`CODE_OF_CONDUCT.md`), security reporting (`SECURITY.md`), and privacy notice (`PRIVACY.md`). The maintainer controls releases/merges but contributors retain their truthful human attribution; no AI assistant is designated as co-author of maintainer commits.

The protected `main` branch uses the `protect-main` ruleset. Propose changes on a separate branch and open a PR. Run `python3 -m unittest discover -s tests -v` before submitting. GitHub Discussions and private vulnerability reporting must be **enabled manually** in repository Settings; adding documentation does not enable these GitHub features.

Do not push new work directly to `main`, use unauthorized third-party assets, publish private user data, or claim legal/regulatory certification. See the PT-BR guide for detailed macOS instructions and official sources.
